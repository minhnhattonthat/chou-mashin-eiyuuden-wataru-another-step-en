# Style reference

Pilot: the prologue opening (R00:0CCF4-0D5A8), translated by the controller (2026-11-14). Every translator matches
this. US spelling. Box = 32 letters x 3 lines incl. the speaker line; write every break as `\n`.

## Voices (JP markers -> English devices)

| Character | JP markers | English devices |
|---|---|---|
| Wataru (10, the hero) | ボク, casual ～だもんね, なんだよ, いっやぁ, ぅええっ | breezy kid talk: "Whoa!", "No way!", "Man,", "way more fun", contractions always; never formal |
| Obaba (old fortune-teller) | じゃ, のぉ, かえ, おまえ, そおうじゃ | crone flavour: "ye", "eh?", "Aye.", "boy", "Mm."; short punchy lines, loses patience loudly (GAAAH!!) |
| Sakuya (ninja-clan princess) | ですわ, ～ましてよ, おほほ, ふふっ, 救世主さま, お初にお目にかかります | refined and gracious, a little haughty: full sentences, no contractions in formal moments, "I daresay", "Oh ho ho!", "Savior-sama", "Wataru-sama" |
| Aragoto (swordsman) | ～ではないか, ～であろう, ぼうや, ふっ, 拙者 | pompous samurai bluster: "I say!", "Hmph.", calls Wataru "boy" / "kiddo" (ぼうや), stiff grandeur that deflates for laughs |
| Warurine | ～だわ, ～なの, small-girl tone | sweet, earnest, a little prim; never sinister before the reveal (docs/synopsis.md) |
| Ryujinmaru | ～だ, ～ぞ, ワタル！ | deep, terse, heroic: "Wataru!", "Leave it to me." |
| Demon sisters | ～よ, おーほっほ, ワタル！ | camp villainy, each her own gimmick (Warutorin: music/enka ban, Warulilith: medals and fitness, Warujo: romance) |
| Generic villagers | dialect per village | plain friendly English; keep each village's obsession (its "one value") in every line, it is the joke |

## Rules shown in the pilot
- Speaker line = the `## Speakers` name + `:` exactly (`オババ：` -> `Obaba:`).
- A page with no speaker line continues the last speaker; it has 3 text lines.
- 【もんじゃ村】 -> Monja Village (no brackets; names are capitalised).
- 「...」 quoted legends -> "..." and the quote may run across pages (close it on the last page).
- 救世主さま -> Savior-sama (honorific kept after a title too).
- Gags keep their timing: one-word ping-pong lines stay one word ("Who is?" / "You are." / "Of what?").
- Stammers: "Y-yes...", "W-Wataru Homurabe."
