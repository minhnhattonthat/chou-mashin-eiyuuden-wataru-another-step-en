# Skill gotchas (one line each: reference file, then the fact)

- references/pipeline.md §Recon: `relsearch.py WORD` with no `--width` found nothing on 16-bit LE text (this game: あ=0x0001); `--width 2` found it at once. Try both widths before concluding the encoding is not kana-ordered.
- references/emulator-qa.md §PCSX-Redux: at this game's title, 6-frame Start/circle presses in a route were ignored; 12-frame presses registered.
- references/platform-ps1.md: a game with no Shift-JIS can carry per-room fonts whose kanji codes are allocated per overlay (same code = different kanji per room); tables must be per room, and `jp_left.py --sjis` will see nothing.
- references/graphics.md §Survey: PS1 games that store graphics as raw VRAM-upload chains (u16 x,y,w,h + data) can be swept with no format knowledge: find the longest chain of plausible headers ending at EOF (prefer the chain with most blocks; a lone big block from inside a tile map can chain to EOF by chance). CLUT rows may start at y=506 with h=16 and wrap past 511.
- references/graphics.md §Survey: sheet.py sizes every tile to the largest image, so mixed-size texture dumps (8x48 frames next to 256x256 atlases) give dozens of near-empty pages; a shelf packer (tools/pack.py here) fit 971 blocks into 23 pages. codex exec -s read-only -i page.png... worked as the independent read-only reviewer for those pages.
- references/platform-ps1.md: `disasm.py xref` and lui/addiu scans miss `lui at,hi; addu at,at,idx; lw x,lo(at)` unless the addu is followed; and table bases built as `base - stride` (1-based index: enemy names at 0x80300 referenced as 0x802EC) never match the first entry. Search for base - stride too.
- references/platform-ps1.md: PS1 games with per-mode fonts: besides the main font file look for config/menu fonts sharing its cell layout (here OUT/CNF_MSG.BIN, same kana cells as MSG_CG, 771 glyphs): render every unknown ~100 KB raw file as 16x16 4bpp glyphs once.
- references/emulator-qa.md §Hooks: a debugger-free free-space trap (fill 0xA5 from on_frame, rescan every 600 frames, log dirty sub-ranges) runs at full speed; write breakpoints over a 128 KB range would need the interpreter. tools/lua/trapwatch.lua in this repo.
- references/emulator-qa.md §emu.py: `--mash` presses for 6 frames; this game's battle menu (like its title) drops 6-frame presses, so a mash-through-battle run sat on たたかう for 15,000 frames. Mash with 12-frame presses (tools/debug/warp.lua `mash=`).
- references/emulator-qa.md §Debug tool: writing the main-loop mode byte from Lua (PS1, PCSX-Redux) reached save, battles, shop, credits and the ending directly from a field state, but one mode (level-up) hung black: modes that expect a caller's setup need the natural trigger (win a battle with GOD on the battle's own HP copy, which differs from the party struct).
- references/pipeline.md §Recon (kanji OCR): for antialiased 16x16 game fonts with a drop shadow, template matching against MS Gothic / Yu Gothic (bbox-normalised, blurred) scored 46% top-1 even on kana: skip it. Reading 20x10-cell sheets at zoom 3 (black on white, shadow index dropped, code above each cell) is fast and near-exact; ~2,500 glyphs took 13 sheet reads. Mark doubtful cells with ? and settle them from the decoded script.
- references/pipeline.md §Extract: event-bytecode text with no per-string pointers: find pages as text runs ended by a terminator and accept them only behind a known header (opcode before, chained after an accepted page, pointer target, or a lui/addiu target in the overlay itself); chaining only from accepted pages kills the garbage that data tables produce. Terminators that take args (8000 n) need an arg count or the arg starts a fake page.
- references/emulator-qa.md §emu.py (PCSX-Redux): `PCSX.GPU.getVRAM()` in nightly-30651 returns 2 MB, not the 1 MB pcsx_lib's comment says; the first 1 MB is the 1024x512 16-bit VRAM (tools/vram.py slices it).
- references/emulator-qa.md §Debug tool: a warp Lua that drives its own presses breaks when emu.py also gets --route-str (the route replaced the warp's input: the run sat in the attract FMV). Warp with --state-out, then play the next run from that state.
- references/pipeline.md §Marker (engine spike): with per-glyph LoadImage of 16x16 cells and a shared font array (src = base + code*128), pre-rendered two-letter cells allocated like kanji need no code change at all; check this before patching render sites (here 124 of them).
- references/pipeline.md §Marker (width gate): on a PS1 game drawing text into a fixed VRAM window buffer, a page with more lines than the buffer (6 vs 3) did not clip: it wrote outside and garbled every later page. Test line count on its own page last, or in its own build, so the overflow can't spoil the other stress pages.
- references/pipeline.md §Width gate: an in-place marker can't show a box's max (it holds the JP length); a stress-only override that runs past its slot over the next strings (here `qa['+ID']` in insert.py, written after every other write) measured sized boxes. And a box that sizes to its text may take the length from a `[cells, ptr]` record, not the terminator: the spill then shows only the JP cells, which is the clue.
- references/pipeline.md §Width gate: one name, two encodings sharing one count: this game's enemy has a 16-bit name (2 letters per cell in English) and an 8-bit header copy drawn for the 16-bit cell count, so English would show half the name in the header. Fill each copy with a ruler AND shorten the other to catch shared counts.
- references/pipeline.md §Marker: with digraph cells and ~190 free codes per font, `[id] text` markers explode the pair count; a global 4-digit marker number (2 cells = 100 digit pairs) + a 13-pair filler whose letters tell the column, with a number->id TSV, fits easily.
- references/emulator-qa.md: PCSX-Redux Lua L.on_exec hooks registered from an on_frame callback (after --state-in) never fire; register them at script load (pass addresses via --var).
- references/emulator-qa.md §Debug tool: press timings tuned on a savestate failed from a cold boot (the battle intro ran longer and silently ate the presses; circles 90 frames apart after ~2,100 frames worked). And battle HP the battle sets after its intro can't be a start-point poke: a delayed one-shot write (warp.lua `late=F:A:V:N`) forced both the loss screen and the win.
- references/pipeline.md §Width gate: some fixed fields are drawn squeezed to half width (here monpet attack names: 16x16 cells shown 8 px wide), so two-letter cells become 4-px letters. Check the original's shot for scaling before giving a field a 2-letters-per-cell budget.
- references/translation.md §Translator dispatch: `codex exec` on Windows (codex-cli 0.167) can't start any process in its sandbox (ShellExecuteExW 1223, file writes fail too), and a worker can't nest agents. Prompt-only works: put brief, style ref, terms and batch in the prompt, `-s read-only -o last.txt`, parse the TSV from the last message (`tools/tl_codex.py`). Call it via shutil.which("codex"): it is codex.cmd.
- references/translation.md §Batch design: the same item name lives in several tables with different field widths (equipment list 16 letters, battle 8x16 list 11): translate the tables first (wave 0), then unify each name to one form that fits its tightest field (`tools/names.py`) before dialogue batches, or "Got X!" messages drift.
- references/translation.md §Validation and merge (assets/batches.py): `merge b1 b2 ..` is all-or-nothing, so one failing batch silently left 10 good batches unmerged, and a later "refresh .out.tsv from script/" step blanked them (recovered from the reviewer pairs files). Merge batch by batch in loops, make `check` (no args) fail on untranslated entries once a draft is complete, and never regenerate .out.tsv from script/ for a batch that isn't fully merged.
- references/translation.md §Review: codex reviewers raise new Critical/Important on every pass (5-6 rounds here before all batches came back clean), and enforce each new glossary ruling on the next pass, so write rulings into glossary.md before re-reviewing. The drafting model applied "keep honorifics" to common nouns ("bride-san", "Father-sama", "trouble-san" from ゴクローさん): lint `[a-z]+-(san|sama|chan|kun)` plus kin nouns, and exempt katakana set phrases from the name+honorific rule.
- references/translation.md §Review: a line whose meaning contradicts its scene ("truly being rescued" while villagers are attacked) can be a misread kanji, not a mistranslation: a room-font glyph read as a kanji the common font already has (救 in CG and M16_R02) is suspect; render it beside lookalikes (`jtext.py sheet`).
- references/translation.md §Validation and merge: match glossary terms on JP with line breaks removed: a word wrapped mid-word (この世/界) left 界 standalone, the check demanded "Layer", and the translator wrote it into the line.
- SKILL.md ground rules: on Windows, Python `open(p, "a")` writes CRLF (polish.md got mixed endings): pass newline="\n". The Write tool strips trailing whitespace, so a TSV value of a single space must be written another way (printf).
- references/platform-ps1.md §Text: a game with its own 16-bit text encoding can still carry Shift-JIS in the memory-card save title (here PRG/MEMORY.BIN 0x0, copied into the save header's 64-byte title field): run `jp_left.py --sjis` in recon, not only at release.
- references/platform-ps1.md §Free space: an all-zero 1 KB run in a PsyQ EXE may be libspu's `_spu_zerobuf` (SpuClearReverbWorkArea DMAs it to SPU RAM in 1 KB chunks), not free: a trap test never sees the DMA read. Find it by the `_spu_t(3, buf, 0x400)` call (lui/addiu buf, a size clamp `sltiu 0x401`); here the compose hook sat there and the clear was patched to 64-byte chunks from a reserved zero tail.
- references/emulator-qa.md §Free space: trap-fill a PRG overlay's tail only up to the next overlay loaded beside it (BALLBAT's tail ran into the ENE overlays at 0x80104800; filling them hung the battle and the failed run was never re-run). Fill after the overlay loads (FILL frame past the scene's AT frame) and run every scene of that mode.
- references/pipeline.md §Checks: a relocation test that compares the bytes at every original reference target (u32 and lui+lo) before/after catches what a writes-only romdiff misses: here it found the libspu zero buffer and table bases landing mid-string. Exempt what the build rewrites on purpose (re-aimed pointers, cell counts, patched instructions) and u32 words inside text units.
- scripts/sheet.py: `--out a/b/x.png` fails with FileNotFoundError when a/b doesn't exist; it should mkdir the parent.
- references/emulator-qa.md §Visual QA / scripts/emu.py --sheet: tour sheets are built at sheet.py's default --div 2, and a reviewer reading them flags every 6x12 / 8x16 pixel-font label as "fragmented, missing strokes" (60 false issues of 216 here, all clean at full scale). Build the review sheets at --div 1 (8 tiles a page); tools/tour_sheets.py does it per scene. Reviewers also flag typing-out pages as orphan last lines: the brief should say to judge breaks only on a complete page.
- scripts/qa_gate.py todo: chunk files are "id<TAB>path" lines, not paths only (the help says "paths only").
- scripts/qa_gate.py todo: chunk files are named chunk_000.. every round, so a reviewer writing verdicts/<chunk>.tsv overwrites the previous round's verdicts for other sheets (44 lost here); name verdict files per round (vqa_codex.py now adds a timestamp).
- scripts/lua/pcsx_lib.lua L.on_write/L.on_read/L.on_exec: silently never fire without emu.py --debugger (JIT); worth a warning in the help or an error from the lib.
- references/emulator-qa.md §Text coverage: on PS1 a dialogue viewer can drive the game's own event start (state var + event pointer) and reload a free-walk snapshot per event with PCSX.loadSaveState inside on_frame; run it in chunks of ~30 events per process: a long run hung the emulator once.
- scripts/lua/pcsx_lib.lua L.on_read: LuaJIT runs out of FFI callbacks ("too many callbacks") at ~1000 breakpoints; merge nearby addresses into span breakpoints and dispatch by address in one callback (tools/lua/readlog.lua). DMA transfers also fire read breakpoints (one hit, width = transfer size, physical address 0x000xxxxx).
- references/emulator-qa.md §Text coverage (PS1, PCSX-Redux): with --debugger (interpreter) this game's ball battles never finish loading (background drawn, UI never appears), so read-breakpoint coverage can't reach battle text from a cold boot; menus/field work. Plan a non-debugger probe (per-frame RAM decode) for such scenes.
- references/graphics.md §Survey: PS1 room/3D texture blocks can be 4bpp even when the upload rect looks 8bpp-sized; a sweep rendered at 8bpp shows 2x-squashed, plausible images (this game's FR room atlases). Check for nibble-pair bytes (D9 7D 77) before trusting a bpp guess. Unknown CLUT: edit by index with a grey palette (gfx.GREY rows).
